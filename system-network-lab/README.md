[開啟課程](https://harfbd.github.io/codex/system-network-lab/) · [36個動畫總覽與GIF下載](https://harfbd.github.io/codex/system-network-lab/animations.html)

中文語音預設開啟，可關閉或重聽；逐步互動等當步講解結束再前進。GIF循環播放，語音依序說明固定情境。GIF以固定情境呈現資料移動及狀態改變；切換逐步互動可調整條件、速度與前後觀察。作答與動畫紀錄僅存在目前瀏覽器，可於第36頁下載JSON。

開啟方式
解壓縮完整檔案，進入dist資料夾，使用現代瀏覽器開啟index.html。
請保留所有程式、樣式及assets資料夾；閱讀與操作不需要安裝套件。

學習內容
全課36頁、6個單元；每頁一張知識圖，另有3張補充圖。
五大單元圖將CPU與記憶單元放在共同的主機外框中，CPU內包含控制與算術邏輯單元。
RAID 5以四顆磁碟示範資料與分散同位檢查；至少三顆的基本條件已保留。
20題概念檢核與18題核心即時練習均加入對應情境圖示，先看懂題意，再選答案與閱讀解析。
每一頁對應一個立體GIF動畫，全課共36個，首頁與側欄也提供全部動畫目錄。每段以imagegen製作立體場景，再加入資料移動、狀態改變與逐步說明。

操作與紀錄
上一頁／下一頁依序學習，目錄可自由跳頁。提供放大字體及知識圖200%、300%放大。
點選「播放立體GIF」即可啟動；可暫停（返回概覽圖）或從頭播放。切換「逐步互動模擬」可前後觀察、調整速度、切換情境與減少移動效果。GIF採畫面標示的固定情境。
按下播放會自動啟動中文語音；可關閉語音或按「重聽講解」。逐步互動等當步語音與動作都完成再前進；手動切步會講解該步。暫停、重播、切換模式或情境、關閉、換頁與離開分頁會停止舊講解。
GIF會循環播放；語音依序說明畫面標示的固定情境，不代表GIF影格與語句逐一同步。中文聲音取決於瀏覽器與裝置的可用語音；若無法播放，仍可閱讀字幕與操作動畫。
動畫的節奏為教學示意，小螢幕可在圖中左右捲動，文字說明會同步顯示目前步驟。
五大單元、記憶體、RAID、網路、DNS、防火牆及指令工作台都是教學模型，不會改動裝置設定或測量真實網路。
完成頁數由學生自行標記，與測驗分數分開。作答可以重做，複習建議依最近一次答案更新。
進度、答案與筆記只保存在目前瀏覽器；換裝置、換網址或清除網站資料，不會自動移轉。
第36頁可下載JSON學習紀錄，包含概念檢核、核心練習、動畫操作紀錄與筆記；目前不提供匯入功能。
GIF播放只記錄操作次數，不自動標記完成；逐步互動走到最後一步才記錄觀看完成，仍不代表已通過概念檢核。
共用電腦離開前請先保留需要的紀錄，再視需要清除本機資料。

animations.html提供36個動畫的主題、可調條件、觀察任務與課程連結。
